# File Organizer

A simple Python automation tool that automatically organizes files into folders based on their file type.

## Features

- Organizes files automatically
- Supports images, documents, music, and videos
- Places unknown file types into an `Other` folder
- Handles duplicate file names safely
- Provides clear terminal messages
- Uses Python's built-in libraries only

## Supported File Types

### Images
- JPG
- JPEG
- PNG
- GIF
- WEBP

### Documents
- PDF
- DOC
- DOCX
- TXT
- XLSX
- PPT
- PPTX

### Music
- MP3
- WAV
- FLAC
- AAC

### Videos
- MP4
- MKV
- AVI
- MOV
- WMV
